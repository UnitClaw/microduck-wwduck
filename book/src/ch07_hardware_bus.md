# 硬件电路与 TTL 总线

> 本章目标：搭建 MicroDuck 的电气系统——供电、舵机总线通信、IMU 接入，并掌握最常见的故障排查（舵机丢包、通信超时、过流保护）。

## 6.1 系统电气架构

```
锂电池 → BMS → 电源分配
                  ├─ RK3566 主控（5V/3.3V 逻辑）
                  ├─ IMU（I2C/SPI）
                  └─ 舵机总线（TTL，串接 15 颗 HD1910）
```
> 关键：**舵机供电与主控逻辑供电要分离**。15 颗舵机同时运动时电流很大，若与主控共地但共电源，会造成主控电压跌落、复位。

## 6.2 电源方案与 BMS

- **电池**：2S（7.4V）或 3S（11.1V）锂电；舵机标称 4.8~8.4V，2S 更稳妥；
- **BMS**：必须带**低压保护**和**过流保护**。低电压时舵机扭矩骤降、位置回读漂移，策略会不稳定；过流会烧舵机驱动；
- 建议加一个**电源软启动**（浪涌限制），避免上电瞬间电容充电电流冲击总线。

## 6.3 飞特 HD1910 TTL 总线拓扑

15 颗舵机通过 TTL 总线**串联（菊花链）**，每颗舵机有唯一 ID：

```
主控 UART(TTL) ── HD1910 ID=1 ── ID=2 ── ... ── ID=15
```
- 波特率：最高 1Mbps，推荐从低速（如 500kbps）开始调试；
- 半双工 TTL：收发共线，需主控端支持方向控制；
- 每颗舵机需先配置 ID 与波特率，**ID 冲突会导致整条总线通信错乱**。

## 6.4 IMU 接入与安装

- 型号：MPU6050 / ICM20948；
- 接口：I2C 或 SPI；I2C 速度有限，建议用 SPI 提高采样率；
- **安装位置**：尽量靠近整机质心，固定在躯干刚性部位；
- **安装倾角**：IMU 的安装姿态会进入姿态解算初值。若安装有倾角，必须在固件里补偿，否则姿态角直接漂移，Sim2Real 失效。

## 6.5 总线故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 某颗舵机无响应 | ID 冲突 / 地址错误 | 重新配置 ID |
| 随机丢包 | 总线过长、信号干扰 | 降低波特率、加总线隔离 |
| 上电后总线卡死 | 供电不足 / 某舵机短路 | 逐颗上电排查 |
| 位置回读漂移 | 供电电压跌落 | 检查 BMS 与线径 |

> ⚠️ 长线干扰：15 颗舵机串接，线缆较长时 TTL 信号易受 EMI 干扰。建议使用屏蔽线，或加总线隔离芯片。这是从仿真到真机最容易忽视的坑。

## 6.6 供电与信号分离的接线规范

1. 舵机电源线（粗线）直接来自 BMS，不经过主控；
2. 主控与舵机仅通过**信号共地**，逻辑电平由主控驱动；
3. 舵机总线端串联一个**限流电阻/熔断器**，保护主控 UART。

## 6.7 工程踩坑实录

- **共电源导致主控复位**：多颗舵机急停时电流尖峰拉低主控电压，系统重启。改分离供电后解决。
- **ID 冲突整条总线瘫痪**：两颗舵机被配成同一 ID，所有指令乱套。逐颗单独上电重配 ID 恢复。

## 6.8 本章小结

你应能搭建一套**分离供电、总线正确、IMU 已接入**的电气系统，并掌握舵机丢包与供电故障的排查方法。
