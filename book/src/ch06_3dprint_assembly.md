# 3D 打印、装配与公差

> 本章目标：把 CAD 图纸变成一台能动的机器鸭。包含完整 BOM 清单、打印参数、装配顺序与公差控制，以及装配后的称重流程（供第 4 章 MJCF 标定使用）。

## 5.1 完整 BOM 清单

| 类别 | 部件 | 规格/数量 | 备注 |
|---|---|---|---|
| 执行器 | 飞特 HD1910 | 14~15 颗 | 双轴磁编码 TTL 总线舵机 |
| 主控 | RK3566 板卡 | 1 块 | 跑 ONNX 推理 + Rust 固件 |

> 采购建议：舵机、板卡、IMU 为关键件，优先选正规渠道；紧固件与线材可本地采购。BOM 采购清单提供推荐采购渠道与备选替代件。

## 5.2 3D 打印参数

| 参数 | 建议值 | 说明 |
|---|---|---|
| 材料 | PLA | 易打印、成本低 |
| 层厚 | 0.2mm | 平衡速度与精度 |
| 填充率 | 20%~40% | 受力件用 40%，轻量件用 20% |
| 支撑 | 按需 | 悬空结构需加支撑 |
| 打印方向 | 轴向受力件竖直 | 提高强度 |

> ⚠️ 打印填充率直接改变整机动力学！20% 与 40% 填充的等效密度不同，会在第 4 章 MJCF 标定时引入误差。**务必记录每批打印的填充率**，并在 MJCF 标定时使用对应的等效密度。

## 5.3 分步装配顺序

1. **先单腿测试**：先打印并装配一条腿（髋、膝、踝），验证舵机装配、转动范围、舵盘固定；
2. **躯干装配**：把 IMU、主控板固定在躯干，走线；
3. **双腿合拢**：两条腿装配到躯干底座，确认左右对称；
4. **总线串联**：按舵机 ID 顺序串接 TTL 总线，避免 ID 冲突；
5. **整机通电测试**：先不加载步态，测试每个舵机能否独立转动、回读位置。

> 强烈建议：**不要一次性打印全套零件**。先打印单腿验证设计，再打整机，避免设计缺陷导致整批报废。

## 5.4 公差控制要点

| 部位 | 公差要求 | 处理方式 |
|---|---|---|
| 舵盘与输出轴 | 过盈配合 | 打印时留出装配余量 |
| 轴承座孔 | 配合精度 | 必要时扩孔或加垫片 |
| 舵机安装孔 | 对准 | 检查两套舵机版本孔位差异 |

3D 打印本身有 ±0.1~0.3mm 的收缩误差，复杂装配建议预留装配间隙，或用**垫片/轴承**补偿。

## 5.5 装配后整机称重（供仿真标定）

Sim2Real 成败关键之一：**仿真模型质量必须与真机一致**。装配完成后执行：

1. **整机称重**：记录整机总质量；
2. **拆分称重**：把每条大腿、小腿、躯干拆开，用精度 0.01g 的电子秤单独称重；
3. **记录到 `data/cad_weigh_records/`**：
```csv
part,target_cad_mass_kg,measured_mass_kg,fill_ratio
thigh_right,0.042,0.038,20%
knee_right,0.020,0.019,40%
...
```
4. 与第 4 章 Onshape 自动计算的 CAD 质量对比，若误差 >5%，回到 Onshape 微调零件密度，重新导出 MJCF。

## 5.6 常见装配问题与排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 舵盘打滑 | 舵盘与输出轴过盈不足 | 换更紧舵盘或加胶固定 |
| 线束干涉 | 走线未沿结构走 | 重排线束，用扎带固定 |
| 重心偏移 | 装配不对称 | 检查左右零件是否一致 |
| 关节卡死 | 打印干涉/间隙不足 | 见 3.6 修正 CAD |
