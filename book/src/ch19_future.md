# 展望与拓展

> 本章目标：为读者指明 MicroDuck 之后的进阶路径——硬件升级、算法进阶、商业化边界。本章是开放的展望，不做完整实现。

## 18.1 硬件升级方向

| 方向 | 说明 |
|---|---|
| 更高算力板卡 | RK3588 / 边缘 GPU，支撑高分辨率视觉 + RL 并行 |
| 深度相机 | 接入 RGB-D，实现稠密感知与避障 |
| 手部执行器 | 增加自由度，探索抓取操作 |
| 更高性能舵机 | 换用扭矩/带宽更高的总线舵机，扩展负载能力 |

> 升级注意：换舵机会改变整机动力学，MJCF 惯性、BAM 参数需重新标定（回第 4、10 章）。

## 18.2 算法进阶方向

### 18.2.1 在线自适应
在真机上根据实时数据微调策略，进一步压缩 Sim2Real gap：
- 残差策略：仿真学基础，真机学修正；
- 在线域适应：实时更新动力学假设。

### 18.2.2 多模态感知策略
- 视觉 + 本体感知融合，进 vLA（视觉-语言-动作）方向；
- 用空间 VLM 引导机械臂/身体动作，实现语义级任务。

> 这是"具身智能"的方向，工作量与研究性远超本书主链路，作为进阶课题。

## 18.3 性能评估与对标

建立量化指标体系，与原版 Pollen MicroDuck 对比：
- 行走速度；
- 抗扰动能力；
- 摔倒恢复成功率；
- 能耗。

> 对比数据可作为本书升级版 / 论文素材，检验国产飞特方案的竞争力。

## 18.4 商业化边界（重要合规提醒）

1. **软件可商用**：Apache 2.0 训练/固件代码可商用；
2. **CAD 不可商用**：CC BY-NC-SA 机械模型禁止商用，**必须重新正向设计**；
3. **品牌与商标**：不得盗用 Pollen/MicroDuck 商标；
4. 若要商业产品，需独立设计 + 自研软件，脱离开源 CAD 模型。

> 这与第 17 章的许可边界一脉相承。商业落地是方向，但必须建立在合规的重构之上。

## 18.5 社区协作与持续迭代

- 维护 `docs/engineering_log/`，记录每次踩坑；
- 开放 Issue / PR，社区共同迭代；
- 书稿与仓库同步更新，读者可复现每个版本。

## 18.6 本章小结

本书主链路（机械→仿真→训练→真机闭环）到此完成。本章为进阶指明方向：硬件升级、算法自适应、性能对标、合规商业化。
