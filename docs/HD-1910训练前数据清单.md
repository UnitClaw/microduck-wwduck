## 二、动态数据 —— 全部 **待实测**，下面是台架和前置

### 1. BAM 单舵机摆锤辨识

四条轨迹（`sin_time_square` / `lift_and_drop` / `up_and_down` / `sin_sin`）是 [BAM](https://github.com/Rhoban/bam) 工具的标准激励。官方 XL330 用 BAM **M6** 模型，参数（【逆向】`microduck_constants.py`）：`kp_fw=200`、`vin_range=(6.5, 8.2)`、`vin_min=6.0`、`delay 3–6 步`。

**推荐组合**（按 2S 电池工作区间和官方口径）：

| | 值 | 理由 |
|---|---|---|
| 电压 ×3 | **6.6 / 7.4 / 8.2 V** | 电池放空 / 标称 / 满电（避开 8.4 顶格） |
| P ×4 | 舵机默认 / 100 / **200** / 300 | 200 对标官方 XL330 固件 |
| 摆长 ×2 | 0.10 / 0.15 m | 与腿长（42 + 49 mm）同量级 |
| 负载 ×3 | 0 / 0.05 / 0.10 kg | 单腿 ~100 g |
| 采样 | **50 Hz**（与控制周期一致），每段 20 s | |

**台架**：URT-2 + 可调电源（7.4 V 限 2 A）+ 摆杆 + 记录脚本。每个采样点记 `timestamp / goal_position / position / speed / load / input_volts / torque_enable / temperature` —— 寄存器 42 / 56 / 58 / 60 / 62 / 40 / 63，一次读 56–63 连读 8 字节。

### 2. 阶跃响应 · 3. 电压响应 · 4. 低速 · 5. 回差 · 6. 重复性

同一台架。**回差**要外部角度参考 —— 手机水平仪 app 贴摆杆上或量角器，编码器在齿轮输出侧，测不到自己的间隙。

**先做这两个，成本最低**：
- 阶跃 ±10° 重复 5 次 → 命令延迟、上升时间、超调
- 回差 ±1° / ±2° 重复 5 次 → 跟厂家 ≤0.5° 对一下

### 7. 控制与通信时序

要主控跑起来 —— 官方 `robotd` 每 5 分钟打一次汇总（达成频率、抖动、总线占用、错误计数），`bench_dynamixel_bus` 单独测总线。**不打 HAT 用第三方转接板时这是第一个要看的数**：错误率不为 0 就是转接板方向切换跟不上 1 Mbps。

### 8. 电源与压降

五工况表，需要分流器或钳形表在电池正极。**同时记电池端和舵机总线端**，差值就是走线 + 保险丝 + 连接器的压降。

### 9. IMU 数据

要 `imu_to_dxl` 板回来、固件写好。静止 60 s 读 ID 200 寄存器 124–136（gyro 3 × i16 + 四元数 3 × fp16）。方向检查按第 5 节那个 mount 四元数，前后左右各倾 10° 看投影重力的符号。

### 10. 足底摩擦

**现在就能做** —— 打印的脚已经在手：倾斜平面法，脚放地板上慢慢抬，滑动瞬间量角，μ ≈ tan θ。木地板 / 瓷砖 / 地毯各 5 次。
